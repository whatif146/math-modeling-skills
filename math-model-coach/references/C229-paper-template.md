# 2022年国赛C题国一论文拆解

> 本题为"古代玻璃制品的成分分析与鉴别"，属于**成分数据分析**题型。
> 三篇国一论文（C065、C155、C229）各自采用了不同的模型组合策略，对比学习可加深对数据分析类题型的理解。

## 论文框架对比

| 维度 | C065（CLR+SVM+层次聚类） | C155（CLR+卡方+决策树+灰色关联） | C229（乘法替换+Dirichlet+决策树+PLS-DA+K-means） |
|------|------------------------|-------------------------------|--------------------------------|
| **数据预处理** | CLR变换；缺失值插补 | CLR变换；缺失值插补 | 乘法替换法+闭合运算 |
| **问题1（风化分析）** | 描述性统计+统计检验 | 描述性统计+卡方检验 | Spearman相关系数+卡方检验→Dirichlet回归预测 |
| **问题2（分类）** | SVM分类器 | 决策树分类 | 决策树+PLS-DA（双重验证） |
| **问题3（亚类）** | 层次聚类 | 决策树细分类 | K-means聚类+PLS-DA特征筛选 |
| **问题4（关联性）** | PCA主成分分析 | 灰色关联分析 | Pearson热力图+Wilcoxon检验 |
| **创新点** | CLR变换消除定和约束 | 灰色关联量化关联度 | 乘法替换+DIR回归+双模型验证 |
| **软件工具** | MATLAB | MATLAB | R+SIMCA |

## C229模型组合实现详解

### 模型1：乘法替换法（缺失值插补）

适用于成分数据中空白值和0值的处理：

```
Step 1: 设定探测范围向量，以每列最小值的65%作为替换值
Step 2: 对每个样本：0值用δ_ij替换，正数值×(1-Σδ_ik/c)调整
Step 3: 闭合运算归一化到100%
```

R代码：`multrepl()`函数

### 模型2：Dirichlet回归（风化前成分预测）

适用场景：成分数据的回归建模（因变量为多元成分，和为100%）

```
Step 1: 将纹饰、类型、颜色、风化转为虚拟变量
Step 2: 构建Dirichlet回归模型
Step 3: 将"风化=1"替换为"未风化=0"→预测风化前成分
```

R代码：
```r
DR_data(y_chuli[, 1:14])
DirichReg(y ~ emblazonry + class + color + weathering, data)
predict(res1, x_yuce)
```

### 模型3：决策树（二分类）

```
Step 1: CLR变换 clr(x) = (log(x₁/g_m), ..., log(x_D/g_m))
Step 2: rpart包构建决策树
Step 3: 提取规则（根节点PbO<1.5→高钾，≥1.5→铅钡）
```

### 模型4：PLS-DA（偏最小二乘判别分析）

```
Step 1: X=CLR变换后的化学成分，Y=类型哑变量
Step 2: SIMCA软件建模，观察Q²值→判断模型有效性
Step 3: 计算VIP值筛选重要特征（VIP>1）
        - 大分类：PbO、K₂O、BaO、SrO
        - 高钾亚类：K₂O、SiO₂、CaO、SnO₂
        - 铅钡亚类：P₂O₅、CuO、Na₂O、Fe₂O₃
```

### 模型5：K-means聚类（亚类划分）

```
Step 1: 手肘法确定K值（fviz_nbclust wss法）
Step 2: K-means聚类（kmeans函数）
Step 3: 以聚类结果为因变量，PLS-DA筛选亚类重要特征
```

### 灵敏度分析方法

| 方法 | 用途 | 具体操作 |
|------|------|----------|
| 多模型交叉验证 | 问题2/3 | 决策树+PLS-DA得出一致结论 |
| CV交叉验证 | 问题3 | 10折交叉验证计算RMSEP，选最优主成分数 |
| 手肘法 | 问题2聚类 | WSS-K曲线选拐点 |
| Q²模型验证 | PLS-DA | Q²曲线交于Y轴负半轴→模型有效 |
