# 变系数扩散类问题的数值格式审计

> 什么时候读这份文档：问题涉及**扩散/传导类偏微分方程**（热传导、水分扩散、渗流、污染物迁移、磁扩散……），且方程里的系数（扩散系数 $D$、热导率 $k$、渗透率）**随状态或空间变化**——尤其是变化量级较大的情形。
>
> 这份文档记录的是一类**极容易通过所有常规自检、却会让结果整体作废**的错误。它的可怕之处在于：常数系数的校验完全查不出来。

---

## 一、错误长什么样

最常见、也最"自然"的离散写法是**节点系数格式**：在节点 $i$ 的方程里，用该节点自己的系数 $K_i$ 同时估计内外两侧的界面通量：

```
(C_i^{n+1} - C_i^n)/dt = K_i * [ (C_{i+1}-2C_i+C_{i-1})/dr^2 + (C_{i+1}-C_{i-1})/(2 r_i dr) ]
                       ↑ 两项都用 K_i
```

它看起来是在离散 $\frac1r\frac{\partial}{\partial r}\!\left(rK\frac{\partial U}{\partial r}\right)$，实际上离散的是

$$K\cdot\frac1r\frac{\partial}{\partial r}\!\left(r\frac{\partial U}{\partial r}\right)=K\nabla^2U$$

而真值是 $\nabla\cdot(K\nabla U)=K\nabla^2U+\nabla K\cdot\nabla U$。**$\nabla K\cdot\nabla U$ 这一项被整个丢掉了。**

## 二、为什么它极难被发现

**$K$ 为常数时，$\nabla K\equiv0$，两种格式代数上完全等价。**

所以：
- 用常数系数做的解析解验证 → 通过
- 用常数系数做的收敛性测试 → 通过
- 用常数系数做的守恒检查 → 通过（数据上少了一类问题）

只有换成**变系数**，两者才分道扬镳。而系数变化越大，偏离越离谱。

### 本次的实测（变系数扩散方程）

取解析已知 $U(r)=2.55-1.5(r/R)^2$、$K(r)=10^{-9}e^{-3r/R}$（沿半径变化 20 倍），$h=R/160$：

| $r/R$ | 真值算子 | 节点格式 | 守恒格式 | 节点格式相对误差 |
|:--|:--|:--|:--|:--|
| 0.3 | $-3.3542\times10^{-6}$ | $-6.0985\times10^{-6}$ | $-3.3541\times10^{-6}$ | **+81.8%** |
| 0.5 | $-8.3674\times10^{-7}$ | $-3.3470\times10^{-6}$ | $-8.3675\times10^{-7}$ | **+300%** |
| 0.7 | $+9.1842\times10^{-8}$ | $-1.8368\times10^{-6}$ | $+9.1828\times10^{-8}$ | **−2100%（符号相反）** |
| 0.9 | $+3.5283\times10^{-7}$ | $-1.0081\times10^{-6}$ | $+3.5282\times10^{-7}$ | **−386%** |

反映到最终结果上：同一物理问题，节点格式给 **33.63 h**，守恒格式给 **57.46 h**——**低估 71%**。

**机理**：节点格式用**内侧较高**的系数估计外流通量，于是系统性高估了边界附近的输运速率。系数衰减越快，高估越严重。

## 三、正确做法

用**守恒型控制体积（有限体积）格式**：

$$
V_i\frac{\mathrm dU_i}{\mathrm dt}=a_{i+1/2}K_{i+1/2}\frac{U_{i+1}-U_i}{h_i}-a_{i-1/2}K_{i-1/2}\frac{U_i-U_{i-1}}{h_{i-1}}
$$

- 面面积 $a=2\pi r_f$，控制体体积 $V_i=\pi(r_{i+1/2}^2-r_{i-1/2}^2)$
- **界面系数取两侧节点值的调和平均** $K_{i+1/2}=\dfrac{2K_iK_{i+1}}{K_i+K_{i+1}}$（保证界面通量连续；算术平均也可用但不推荐）
- **首末单元是半格**：有限体积积分必须用半格测度，否则边界通量会系统性偏离

```python
def step_fv(U, K, H, Uair, dt, r, N):
    """守恒型控制体积，后向欧拉。r 可以是非均匀/分级网格。"""
    import numpy as np
    from scipy.linalg import solve_banded
    K = np.maximum(np.asarray(K, float), 1e-300)
    Kf = 2*K[:-1]*K[1:]/(K[:-1]+K[1:])          # 界面调和平均
    rf = 0.5*(r[:-1]+r[1:]); hf = np.diff(r)
    af = 2*np.pi*rf
    V = np.zeros(N+1)
    V[0]   = np.pi*rf[0]**2                       # 中心半格
    V[1:N] = np.pi*(rf[1:]**2 - rf[:-1]**2)
    V[N]   = np.pi*(r[-1]**2 - rf[-1]**2)         # 边界半格
    n = N+1; lo,di,up,rhs = (np.zeros(n) for _ in range(4))
    i = np.arange(1, N)
    cin  = dt*af[i-1]*Kf[i-1]/(V[i]*hf[i-1])
    cout = dt*af[i]  *Kf[i]  /(V[i]*hf[i])
    lo[i], di[i], up[i], rhs[i] = -cin, 1+cin+cout, -cout, U[1:N]
    c0 = dt*af[0]*Kf[0]/(V[0]*hf[0]); di[0], up[0], rhs[0] = 1+c0, -c0, U[0]
    di[N] = 1 + dt*(af[N-1]*Kf[N-1]/hf[N-1] + 2*np.pi*r[-1]*H)/V[N]
    lo[N] = -dt*af[N-1]*Kf[N-1]/(V[N]*hf[N-1])
    rhs[N]= U[N] + dt*2*np.pi*r[-1]*H*Uair/V[N]
    ab = np.zeros((3,n)); ab[0,1:] = up[:-1]; ab[1,:] = di; ab[2,:-1] = lo[1:]
    return solve_banded((1,1), ab, rhs)
```

## 四、三道审计（交付前必做，缺一不可）

### ① 截断误差检验 —— 查"格式对不对"

取**解析已知**的 $U(r)$ 与**变化足够大**的 $K(r)$，直接比较两种算子与真值：

```python
true = K*U_rr + K*U_r/r + K_r*U_r          # ∇·(K∇U)
node = K*((Up-2*U0+Um)/h**2 + (Up-Um)/(2*r*h))   # 节点格式（应有巨大误差）
cons = (rp*Kp*(Up-U0) - rm*Km*(U0-Um))/(r*h**2)  # 守恒格式（应 ~0 误差）
```

判据：守恒格式的相对误差应在 $10^{-10}$ 量级；节点格式会出现 $10^0\!\sim\!10^2$ 量级的误差。**这一步是唯一能直接抓住格式错误的检验。**

### ② 守恒审计 —— 查"守不守恒"

域内存量变化必须等于边界通量积分：

```python
dW = 2*np.pi*np.trapz(C_after*r, r) - 2*np.pi*np.trapz(C_before*r, r)
F  = 2*np.pi*R*H*(C[-1]-Cair)*dt
# 累计 sum(dW) 与 sum(F) 的相对闭合误差应 ~1e-12，而不是 1e-2
```

闭合误差不为零 → 格式在边界处丢通量（最常见的就是半格测度用错）。

### ③ 独立复算 —— 查"实现对不对"

**换一个代码路径完全独立的求解器**复算同一方程。最省事的做法：保留你的空间离散，把时间积分换成 `scipy.integrate.solve_ivp(method='LSODA')`。

> ⚠️ 注意 `solve_ivp` 的事件检测可以用来捕捉"某个量首次跌破阈值"的时刻，比自己在时间步上打点精确得多：
> ```python
> def ev(t, y): return y[0] - threshold
> ev.terminal = True; ev.direction = -1
> sol = solve_ivp(rhs, [0, tend], y0, method='LSODA', events=ev, rtol=1e-8)
> t_star = sol.t[-1]
> ```
>
> ⚠️ **传参陷阱**：很多物性函数收的是**摄氏度**而不是开尔文。把 50 ℃ 写成 323.15 会让 $e^{-3850/T}$ 偏大两个数量级，复算结果快 5 倍——而你会误以为是自己主程序错了。**复算前先确认每个函数的单位约定。**

三条都过，才能排除"格式错"与"实现错"两类问题。

## 五、分级网格：当系数形成边界层时

若系数随状态**指数衰减**（如 $D\propto e^{-a/C}$），干燥/反应前沿会把边界附近压成一层几乎不透的"干壳"。此时

- 均匀网格收敛**极慢**：实测 $N=80$ 给 87.2、$N=640$ 仍在 57.5（真值 57.46）
- 改用**向该边界分级**的网格，$p=2$ 时 $N=160$ 即收敛到 0.01%

```python
def grid(N, p=2.0):                 # 向 r=R 加密
    i = np.arange(N+1)/N
    return 1.0 - (1.0 - i)**p       # r_i = R * grid(N,p)
```

**必须给"网格 + 时间步"双重收敛表**，而不是只声明"取了 N=200"。若只有均匀网格的收敛表，评委会问：为什么加密到 640 还没收敛？

## 六、一句话总结

> **系数是变的，格式就必须守恒；而守恒性只能用变系数的情形去验——用常数系数验一万遍也没用。**
