# 论文红线与格式核对清单

> **这不是权威文本。** 赛规每年会改，本文件只给「该核对什么、去哪核对、怎么自查」。
> 每次赛前用当年文件替换本清单的判断；本文件里出现的具体数字只作默认值，与当年文件冲突时以当年文件为准。
> 必须核对的四份：①当年竞赛章程（参赛与评奖规则）②论文格式规范 ③关于使用人工智能工具的规定 ④赛题页的评阅要点/评分细则。

---

## 一、提交物清单

| 交付物 | 要点 |
|---|---|
| 论文（PDF） | 每页编号；文件命名与提交系统要求一致；PDF 内不出现学校、姓名、队员信息 |
| 支撑材料 | 代码、数据、中间结果；附运行说明（环境、命令、耗时） |
| 《AI 工具使用详情》 | 固定文件名，按当年规定命名；内容见第四节 |
| 承诺书/编号页 | 按当年模板，签名与编号不得遗漏 |

---

## 二、论文结构与顺序（硬顺序，不能乱）

```
第 1 页：标题、摘要、关键词
第 2 页起：正文（问题重述 → 问题分析 → 模型假设 → 符号说明 → 模型建立与求解
          → 结果分析与检验 → 模型评价与推广）
其后：参考文献
最后：附录（代码、详细数据、推导）
```

- **摘要一页**，四要素齐：问题与方法、关键结果（带数值）、创新点（带证据等级）、边界与局限。评委常凭摘要分级。
- **正文 15–20 页**为惯例区间。超过 20 页先查当年格式规范是否设上限；页数不设上限也不等于可以堆长。
- 图表编号连续，正文引用与图注一一对应；每张图有单位与数据来源。
- 附录代码与正文方法必须一致，变量名做过去标识化处理。

---

## 三、AI 使用的三条红线

1. **必须声明**：按当年规定，在**参考文献之前**单设《AI 工具使用声明》（2026 年规定的做法，需按当年文件再核）。
2. **必须留详情**：支撑材料附《AI 工具使用详情》，固定文件名，内容包括——工具名称与版本、使用目的与环节、提示方式与过程、对输出的核验与人工修改情况。
3. **必须核验**：声明内容与实际使用一致。虚假声明、或把未经核验的 AI 输出直接作为核心成果，取消评奖资格。

自查三问：声明的位置对不对？详情文件在不在、内容全不全？声明里写的和实际用的（含最后一次临时加的）是否一致？

---

## 四、评阅要点对齐（拿到要点后必做）

逐条标「已覆盖 / 部分覆盖 / 未覆盖」，重点排查**明写但最容易漏**的四项：

- 程序运行时间
- 算法时间复杂度
- 数据预处理说明
- 结果的多个指标及其权重排序
- 指定的结果文件与表格格式

若解题路线与要点建议的路线不同，**必须显式对照论证**（完备性 / 合理性 / 有效性三条），不要指望评委自己看懂。

---

## 五、常见扣分项（按出现频率）

| 项 | 表现 |
|---|---|
| 摘要空泛 | 没有具体数值、没有方法名、没有结论差异 |
| 假设凑数 | 「假设所有人理性」这类无数据支撑的假设 |
| 无基线 | 直接上复杂模型，没有对照 |
| 灵敏度缺失或造假 | 只给 ±5% 无依据，或扰动后结论不变也不解释 |
| 图表无单位 | 坐标轴、表格缺单位与口径 |
| 结构过满 | 每节凑三段、整段加粗、长句成串（AI 痕迹三类） |
| 附录与正文脱节 | 代码方法≠正文方法，变量名未处理 |
